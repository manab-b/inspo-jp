# デモ：新宿の歯科医院

`recommend_jp` に次のブリーフを渡して生成しました。

> 新宿の歯科医院サイトを作って。信頼感重視、予約導線あり

## 返ってきた推奨の要約

| 項目 | 値 |
| --- | --- |
| 業界 | `booking` |
| トーン | `trust` |
| マクロ | `booking-local`（地域店舗の予約） |
| 法令セット | `booking` |
| 参照スラッグ | `epark`, `haisha-yoyaku`, `hotpepper-beauty`, `hotpepper-gourmet`, `jalan`, `ikyu` |

マクロの流れは **トップ → メニュー／診療案内 → スタッフ・設備 → 予約 → アクセス → 店舗情報** です。メモどおり、予約を第1CTA、電話番号をヘッダー固定、姓名＋フリガナ、地図と診療時間を同じ視線に置いています。

配色比（墨 0.62 / 紺 0.22 / 生成り 0.12 / アクセント 0.04）と余白（セクション上下 72px、ガター 24px、幅 1080px、タップ 44px）は DESIGN.md の提案をそのまま使っています。

## ファイル

- `shinjuku-dental-recommend.json` … `recommendJp()` の戻り値（整形済み）
- `shinjuku-dental.html` … 上記のマクロ・ルール・フォーム仕様・法令・コンポーネント構造を単一 HTML に適用したランディングページ

HTML はビルド不要です。ブラウザで直接開けます。Noto Sans JP（Google Fonts）以外の外部素材は使いません。

## 著作権上の扱い

参照カタログ（EPARK など）は **構造参考のみ** です。実在医院のロゴ・写真・キャッチコピーは複製していません。文言・医院名・住所はすべてオリジナルのプレースホルダです。
